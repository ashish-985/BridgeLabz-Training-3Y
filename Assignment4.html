20. Important Head Elements

  • <title> - Defines the title shown in the browser tab.
  • <meta> - Provides metadata such as charset, description and author.
  • <base> - Defines the base URL for relative URLs.
  • <link> - Connects external resources such as a favicon.
  • <style> - Defines CSS within the HTML document.
  • <script> - Adds JavaScript to the webpage.
